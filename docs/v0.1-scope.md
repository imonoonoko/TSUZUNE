# TSUZUNE v0.1 Scope

## Product statement

ローカルのMarkdownファイルを、フォルダ・検索・Wikiリンク・バックリンクで整理できる、1人用のWindowsメモアプリ。

## Success conditions

1. TSUZUNEだけで日常のMarkdownメモを作成・編集・整理できる。
2. Wikiリンクとバックリンクを使ってノート間を往復できる。
3. 保存失敗や外部変更が起きても、編集中の内容や既存ファイルを黙って失わない。

## Included

- 単一Vault
- Markdown編集とプレビュー
- 600msの自動保存
- ノート・フォルダ作成
- 名前変更
- ノート移動
- `.trash`への復元可能な削除
- Wikiリンク、リンク先、バックリンク
- 未作成・曖昧・無効リンクの表示
- ファイル名・パス・本文の部分一致検索
- 最後のVault・ノート復元
- 外部ファイル変更の監視と競合解決
- Windows x64ポータブル版

## Deferred

- AI、MCP、ベクトル検索
- グラフビュー
- タグ、添付ファイル、デイリーノート
- クラウド同期、アカウント、共同編集
- プラグイン、テーマストア
- 複数Vault同時利用、タブ、分割ペイン
- フォルダ移動

## Release checks

- TypeScript型検査が成功する。
- 自動試験が全件成功する。
- ポータブル版が起動し、preload APIと画面が読み込まれる。
- テストVaultで最後のノート、Wikiリンク、バックリンク、未作成リンクが表示される。
- 編集内容がMarkdown原本へ自動保存される。
- ソースと配布物が非公開リポジトリに保存される。
