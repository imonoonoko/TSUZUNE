# ブックマークの対象

ファイル・見出し・保存した検索に加えて、Vault 内のフォルダーをブックマークできます。

- ファイル一覧のフォルダーで右クリックまたは Shift+F10 を押し、ブックマークを追加・編集します。タイトルとグループは任意です。
- ブックマーク一覧でフォルダーをクリックするか Enter を押すと、ファイル一覧に切り替わり、祖先と対象フォルダーが展開されます。フォーカスは対象行に移ります。
- 対象フォルダーが見つからない場合はブックマーク一覧にその状態を表示します。登録済みのブックマークは一覧から削除できます。Vault のルートは登録対象外です。

フォルダーも既存の `.tsuzune/bookmarks.json` に保存されます。ブックマークの作成・編集・削除はノートや対象フォルダーを変更しません。
