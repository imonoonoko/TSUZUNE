# ファイル一覧

- ファイル一覧の上部で名前・更新日・作成日を昇順または降順に切り替えられます。作成日が不明な項目は末尾に表示します。「アクティブノートを追従」をオンにすると、ノートを切り替えたときに親フォルダーが開き、一覧の該当位置に移動します。設定はVaultごとに保持されます。
- Ctrlで項目を追加・解除し、Shiftで表示中の範囲を選びます。「まとめて移動」で移動先を選ぶか、選択項目をフォルダーへドラッグします。選択に親フォルダーと子項目が含まれる場合は、親を一度だけ移動します。
- 移動前に見えている同名の衝突を確認します。途中でエラーが発生した場合は処理を止め、移動済みと未移動の項目を表示します。移動先を確認してから残りをやり直してください。
- フォルダーの右クリックメニューからブックマークを作成できます。ブックマークを開くとファイル一覧に切り替わり、対象のフォルダーが表示されます。
