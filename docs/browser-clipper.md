# Browser Clipper

TSUZUNE Browser Clipper は、Chrome／Edgeで表示中のWebページを、分類せず`01_受信箱`へMarkdownとして受け取るためのMV3拡張です。source実装と自動検証は完了しています。インストール済み本番との一致は最新のproduction receipt、実ブラウザでの利用可否は手動確認を別々に正本とします。

## 使い方

1. TSUZUNEを起動し、Vaultを開きます。アプリとVaultが利用できない場合は保存できません。
2. TSUZUNEの通知領域メニューから「ブラウザ拡張フォルダを開く」を選びます。Chrome／Edgeの拡張機能管理画面で「デベロッパーモード」→「パッケージ化されていない拡張機能を読み込む」から、そのフォルダを読み込みます。開発時はrepository直下の`browser-extension`です。
3. TSUZUNEの通知領域メニューから「ブラウザ拡張を接続」を選びます。表示され、クリップボードにもコピーされた6桁コードは、一度だけ使える5分間有効のペアリングコードです。
4. 拡張のポップアップへ6桁コードを入力します。ペアリング後、「このページを受信箱へ保存」を押すと現在のページを一度だけ保存します。以後も保存したいページで拡張アイコンを開き、同じボタンを押します。

ペアリング情報は同じPCのローカルに保存されます。再ペアリングが必要になった場合は、TSUZUNEを起動して新しいコードを発行します。拡張の公開ストア登録や自動更新はこのsliceの範囲外です。

## 保存される内容

通常のWebページでは、ページタイトル、URL、取得時刻、取得ID、ページ本文の限定されたテキストを保存します。Mozilla Readabilityで記事本文と著者・概要を抽出し、記事として判定できない短文ページや特殊なページでは、従来の表示DOM抽出へ自動で戻ります。利用者が抽出方式を選ぶ操作はありません。

YouTubeでは動画URL、動画ID、タイトル、取得時刻、説明・選択テキストに加え、次の順で文字起こしを探します。

1. すでに画面へ表示されている文字起こし
2. ページの「文字起こしを表示」を開いて短時間待った結果
3. 現在の動画IDと一致するページ内字幕トラック（`youtube.com`内だけ）
4. ここまでで取れなかった場合、または取得結果が途中で切れた場合、TSUZUNE側でローカルの`yt-dlp`を一度だけ実行した字幕トラック

保存後のポップアップには、TSUZUNEが最終的に保存した結果として「字幕あり」「字幕を確認できず」「表示中の情報のみ」のいずれかを表示します。ノートにも`youtube_transcript_status`を保存するため、字幕トラックが存在しても本文を取得できなかった場合を成功扱いしません。「字幕を確認できず」はクリップ時点で手掛かりがなかったという意味で、動画に字幕が存在しないとの断定ではありません。

ローカル抽出は、このPCの`PATH`から`yt-dlp`を見つけられる場合だけ働く任意のフォールバックです。手動字幕と自動字幕のJSON3を一時フォルダへ取得し、文字起こしへ変換後に一時ファイルを削除します。`--ignore-config`で利用者・システムの`yt-dlp`設定を読み込まず、ブラウザのCookieやログイン情報、PO Token provider、リモートコンポーネント、クラウド文字起こしサービスは使いません。`yt-dlp`がない、字幕がない、またはYouTube側の制限で取得できない場合も、動画情報だけのクリップは従来どおり保存します。

各ノートには`source_url`、`source_type`、`captured_at`、`capture_id`などの出典情報と「外部ソース・未検証」の注意書きを含めます。タイトルは安全なコード表記、本文は動的なコードフェンス内へ置き、非信頼データがノート構造やWiki linkを壊さないようにします。

同じページを再度保存した場合も既存ノートを上書きせず、新しい受信箱ノートを作ります。クリップ自体が取得時点の原資料スナップショットなので、汎用的な操作履歴・実行ログ・新しい`50_履歴`は作りません。既存のlegacy `50_履歴`は保護されたままです。

## 境界と安全性

- 通信は同じPCの`127.0.0.1`だけを使い、拡張IDを固定したペアリング済み拡張からの要求だけを受け付けます。
- Webページへの一時アクセスは、利用者が拡張を押したタブだけに有効な`activeTab`を使います。全サイト常時読取権限は要求しません。
- Readabilityは拡張内へ固定バージョンを同梱し、実行時に外部コードを読み込みません。第三者ライセンスは`browser-extension/vendor`に同梱しています。
- YouTubeのローカル字幕フォールバックは、検証済みの動画IDから組み立てた固定URLだけを引数配列で`yt-dlp`へ渡します。shell、ブラウザCookie、常駐プロセスは使いません。
- 拡張から保存先path、任意ファイル名、更新・削除・移動操作は指定できません。保存先は常に`01_受信箱`です。
- 通常の本文・選択範囲・取得済みYouTube字幕は途中で切らずに保存します。異常に大きな要求による停止を防ぐため、拡張からTSUZUNEへの一回の通信には8 MiBの安全上限があり、超過時は一部保存せずエラーにします。
- Web本文は事実確認済みの知識ではありません。秘密情報や個人情報を含むページを保存しないでください。
- この境界は同じユーザー権限で動く悪意あるローカルプログラムへの防御を意味しません。ペアリングコードとローカル環境を保護してください。

## トラブルシューティング

- **ペアリングできない**: TSUZUNEが起動中でVaultを開いているか確認し、通知領域から新しいコードを発行します。コードには有効期限があります。
- **保存できない**: TSUZUNEのVault状態、拡張の権限、拡張を読み込んだ固定フォルダが正しいか確認します。アプリ終了中は保存できません。
- **本文が少ない**: 記事判定できないページでは表示DOMへ自動で戻ります。ログイン壁、埋め込みPDF、iframe内本文、動的に未読込の範囲は完全取得を保証しません。
- **「字幕を確認できず」と表示された**: クリップ時点のページには文字起こしの手掛かりがありません。字幕が存在しないとの断定ではなく、動画自体は受信箱へ保存されています。
- **「表示中の情報のみ」と表示された**: ページ内取得とローカル字幕フォールバックの両方で本文を取得できませんでした。`yt-dlp --version`が成功するか、動画に字幕があるかを確認してください。失敗を字幕取得済みとは記録しません。
- **「字幕は一部」と表示された**: ページ側で途中になった字幕をローカル取得でも完全版へ置き換えられなかった状態です。取得できた範囲は失わず保存します。
- **同じタイトルのノートが増えた**: これは意図した動作です。取得ごとに別の出典スナップショットを残します。
