# Markdown表の編集

目的は、ノート中の比較表をセル単位で編集し、行・列を操作できるようにすること。通常のMarkdownを保存し、既存の自動保存・競合保護・版履歴を使う。

## 操作と受入条件

- Source／Live Previewの「表を編集」でカーソル位置の表を開く。Live Previewの表からも編集を開ける。セルにはインラインMarkdownを入力する。
- 見出し・本文セルを編集し、行・列の追加、削除、前後への移動、列の左／中央／右揃えを行える。見出し行と最後の1列は削除しない。
- 「適用」で対象の表だけを変更し、前後の本文・frontmatterを保持する。1回のUndoで適用を取り消せる。「キャンセル」／Escapeでは変更しない。
- 編集中に本文・対象ノートが変わった場合や読み取り専用になった場合は、古い内容を適用しない。IME変換中のEnterを確定・適用と誤認しない。
- 既存のGFMパーサーを使い、コードブロック・frontmatterを表と誤認しない。セルのMarkdownとエスケープ済みパイプを保持し、新しいパイプはセル境界にならないよう保存する。
- 「表を挿入」で現在のブロックの後に2列の表を作れる。選択した文字を置き換えない。閉じていないコード・HTML・frontmatter内など、表として挿入できない位置では理由を表示して止める。引用・リスト内の入れ子表はソース編集を使い、GUIから書き換えない。

## 使い方

編集／Live Previewで表の中にカーソルを置き、書式ツールの「表を編集」を押す。Live Previewでは表示中の表の下にある「この表を編集」も使える。セルを選ぶと、その行・列を対象に追加・削除・移動や列の配置を操作できる。セルはTab／Shift+Tabでも移動できる。

「表を適用」で本文と自動保存へ反映し、Ctrl+Z／Ctrl+Yで表全体の変更を戻す／やり直す。「キャンセル」やEscapeは下書きを破棄する。変更なしで適用した場合は元の書式を保持する。編集した表の区切り・空白は通常のMarkdown書式へ整えるが、表の外の本文は保持する。

## 今回の範囲

通常のMarkdown表。Basesのデータ編集、計算式、セル結合、CSV入出力、表全体の並べ替え、ドラッグ操作は追加しない。新しい依存・DB・MCP書込APIも不要。

## 検証

`npm exec vitest -- run tests/markdown-table.test.ts tests/markdown-table-editor.test.tsx tests/live-preview.test.tsx` で変換・編集・挿入・競合・Undo／Redoを確認する。隔離した実アプリでは表の編集、保存と再読込、実キーのUndo／Redoを確認する。
