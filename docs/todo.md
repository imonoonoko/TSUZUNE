# ノート活動のToDoリスト

左のアクティビティバーの「ノート活動」から開きます。概要の下のToDo欄に入力してEnterまたは「追加」で登録し、チェック欄で完了を切り替えます。未完了を先に表示し、完了済みは折りたたんでいます。「完了済み」を開いてチェックを外すと未完了へ戻せます。「削除」で一件を取り除きます。

大量の項目はリスト内で縦にスクロールでき、ノート活動のページ全体もスクロールできます。長いタイトルは一覧で3行まで表示し、カーソルを重ねると全文を確認できます。「ToDoノートを開く」から元のMarkdown全体を開けます。タスクに既存ノートのWikiリンクや相対Markdownリンクがある場合は「…を開く」から移動できます。未作成・曖昧な参照先を自動で作成・選択しません。

Vaultごとにルートの`ToDo.md`を使います。開くだけではファイルを作らず、最初の追加で作成します。通常のMarkdownなので、ノートとして開いたり、他のeditorで編集したりできます。例:

```md
# ToDo

- [ ] 読みかけのノートを整理する
- [x] 買い物
```

対象はこのファイルの先頭から始まる`- [ ] `／`- [x] `／`- [X] `の行です。Frontmatter、コードブロック、字下げされた子項目は一覧に含めません。周囲の文章・BOM・既存の改行は保持します。閉じていないFrontmatter／コードブロックの末尾には追加せず、修正を促します。

他の場所で同時に編集されると上書きを拒否します。入力中の新しいToDoは保持されるので「再読込」で現在のファイルを確認してから操作をやり直してください。既に開いているノートの未保存の編集はToDoの書込み前に保存し、保存できなければToDoの書込みも止めます。既存の`ToDo.md`をそのまま使い、配置変更に伴う移行や本文の書換えはしません。

同じ画面の[ノートをまたぐタスク一覧](task-aggregation.md)にも `ToDo.md` のタスクが表示されます。どちらの一覧で完了を切り替えても、両方に反映します。
