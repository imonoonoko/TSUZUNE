# TSUZUNE v0.6.0 公開Release・本番受入

更新日: 2026-08-26（JST）

## 結論

TSUZUNE v0.6.0をcommit `6a519865eaac6813a6c82072101794504dc08323`、tag `v0.6.0`として公開し、GitHubのLatest Releaseへ設定した。本番更新gateは10/10 PASSで、インストール済みTSUZUNEは0.6.0、production profileは前後58 filesでbyte不変だった。

公開前に、public GitHub update feedでもGitHub tokenを必須にしていた不整合を回帰testで再現した。tokenがない場合も`electron-updater`へ更新確認を委譲し、tokenが既に利用可能な場合だけprocess内で一時利用する最小修正へ変更した。tokenはTSUZUNEの設定やVaultへ保存しない。

## 主な変更

- Quick Switcher、Command Palette、全文検索、workspace tab、左右sidebar独立開閉を含むdaily workspace。
- template、folder-aware note作成、衝突時に上書きしないmove／trash、鮮度表示、attachment、bookmark、Graphの改善。
- Codex／Freebuff共通16 MCP tools、revision付きwrite、Delivery info、Drive preview／apply、単一Markdown move preflight／apply。
- 宣言済みread-only MCP操作について、cold／malformed／noncanonical fixtureを含むVault／profileのliteral zero-write化。
- 明示preview／applyを維持する任意のGoogle Drive同期、2 profile roundtrip、既定preserveを保つopt-in deletion propagation。
- public GitHub update feedの匿名更新確認を妨げていたtoken gateの修正。
