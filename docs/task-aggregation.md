# ノートをまたぐタスク一覧

複数ノートのMarkdownタスクを集約し、元の行への移動と完了切替ができます。

## 振る舞いと保存

- ノート活動から「ノートのタスク」を開く。通常のMarkdownノート（ルートToDo.mdも含む）の未完了タスクをノート名・本文とともに表示し、再読込できる。
- Frontmatter・fenced code・保護された履歴／情報源・利用者の除外ファイルは対象外。通常の箇条書きタスクと入れ子の子タスクを扱う。
- 元ノートへの移動は保存済み本文の該当行を選択する。移動先が変わった場合は再読込を促し、同名タスクを推測で選ばない。
- 完了にすると対象のチェック欄だけを変更する。「完了済み」を開けば同じ行を未完了へ戻せる。元の本文、改行、BOMを保持し、新しいノート・専用DBを作らない。
- 書込みは既存のrevision検査と履歴・保存経路を使う。未保存draft、外部変更、削除／移動、Vault切替と競合した時は上書きしない。失敗しても本文と一覧の対象を失わず、再読込から再試行できる。

## 対象外

タスクの追加と削除は[ルートToDo欄](todo.md)か元ノートで行います。

## 受入と証拠

1. 複数ノート・入れ子・同名項目を正しく集約し、Frontmatter／コード／除外対象を含めない。完了済みは初期状態で折りたたむ。
2. 実UIで元の行へ移動でき、完了／未完了の切替が保存・再読込後に維持される。変更した文字以外の本文が一致する。未保存編集とrevision競合を保全する。
