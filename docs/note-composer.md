# ノートの部分抽出・統合

通常のMarkdownノートを開き、見出し横の「抽出・統合」から実行する。変更前後の本文と対象ファイルを確認してから保存する。

## 部分抽出

「編集」またはLive Previewで本文を選択してから開く。新しいノートのパス、または既存ノートと挿入位置（末尾／本文の先頭）を指定する。新規ノートは既存フォルダーに作成する。

「元本文の残し方」で「リンクに置換」（初期値）・「埋込みに置換」・「何も残さない」を選ぶ。選択箇所には、それぞれ `[[移動先]]` または `![[移動先]]` を残す。埋込みは移動先ノート全体を表示するため、既存ノートに抽出する場合は、そのノートの既存本文も表示対象になる。この選択は今回の抽出に適用し、次に開くとリンク置換から始める。

「何も残さない」は選択範囲の文字列だけを取り除き、リンク・空白・改行を挿入しない。抽出先への本文保存と同じ処理で実行し、取消や保存前の失敗では取り除かない。

残し方やテンプレートを変更するとプレビューは解除される。「変更を確認」で実際の変更前後を見直してから実行する。キャンセルや保存前の検証失敗では抽出元・移動先の本文を変更しない。途中まで保存された処理は以下の既存の復旧手順に従う。

移動する見出し・ブロックIDを指す参照は移動先へ更新し、元ノート全体や残った見出しへの参照は維持する。移動した本文の相対Markdownリンクと添付ファイルパスも移動先に合わせる。

### 抽出先テンプレート（2026-10-27）

選択範囲を新しいノートへ抽出する時、「抽出先テンプレート」から既存テンプレートを選ぶ。設定中のテンプレートフォルダーと組込みテンプレート表示設定を使い、初期値は「テンプレートなし」。今回の抽出だけに適用する。既存ノートへの追記・全体統合では表示せず、切替時は選択を解除する。

- `{{content}}`: リンクと添付パスを移動先に合わせた抽出本文。独立した本文行に一回だけ置く。省略したテンプレートにも本文を末尾へ追加し、本文を失わない。
- `{{source_title}}`: 元ノートのファイル名（拡張子なし）。
- `{{title}}`: 新規ノートのファイル名（拡張子なし）。
- `{{date}}`・`{{time}}`・`{{datetime}}`: 既存テンプレートと同じローカル日時・書式指定。ダイアログを開いた日時を固定し、確認と実行で一致させる。

抽出本文やファイル名に含まれる変数は再展開しない。題名変数は既存テンプレートと同じくファイル名をそのまま展開するため、リンク・コード・YAMLなどの記法はテンプレート側で指定する。展開後のYAMLが不正なら保存を止める。本文位置の重複、構文途中・Frontmatter・コード等への挿入、曖昧な見出し・ブロックID、参照リンク・脚注・数式の解釈変更など、安全に本文を保持できないテンプレートは保存前に拒否する。テンプレート自身は書き換えない。プレビュー後のテンプレート変更・削除・設定変更も再確認の対象にする。本文の位置はテンプレートで決まるため、選択中は「挿入位置」を変更できない。

### ノート抽出を開くショートカット

通常のMarkdownノートの「編集」またはLive Previewで本文を選択し、`Ctrl+Shift+E` を押すと、同じ抽出画面を開く。本文エディターにフォーカスがあり、空でない選択がある時だけ動く。選択なし、プレビュー、検索欄など別の入力、Canvas・Base・添付では開かない。IME変換中・キーリピート・別のダイアログ表示中・処理中も実行しない。

設定の「ショートカット」から「ノート抽出を開く」の割り当て・解除・初期値復元ができる。保存済みのカスタム割り当てを自動で変更しないため、以前のカスタム設定にこの操作がなければ未割り当てになる。

開く前に編集中の本文を保存し、保存競合があれば開かない。抽出範囲を保持して既存のプレビューと実行確認を通し、キャンセル後は本文の操作位置へ戻る。ショートカットだけで抽出を確定しない。

## 全体統合

選択がない状態で開くか、操作を「ノート全体を統合」にする。既存ノートの本文の先頭または末尾へ移し、統合元への参照を更新する。元ノートは既存の `.trash` に元の内容で退避する。

既存ノートのプロパティは先頭に残し、互換性のある元ノートのプロパティを統合する。値の衝突、重複する参照先、構造を壊す選択範囲など、安全に変換できない内容はエラーとして保存を止める。

## 変換できる範囲

- 普通の本文は段落の途中から抽出できる。見出しを移す場合は、その見出しが受け持つ本文まで選ぶ。ブロックID（英数字とハイフン）はIDと参照対象のブロックを一緒に選ぶ。
- 見出しの名前・生成されるリンクID・ブロックIDが曖昧になる重複を拒否する。リンク、コード、引用、リスト、強調、HTMLなどの構文の途中を切り出す選択と、閉じていないコードフェンスやHTML・コメントを拒否する。
- 参照形式のMarkdownリンクでは、必要な定義を抽出先にも保持する。定義名の衝突、移動によって既存テキストが新たにリンクになる場合など、リンクの解釈が変わる組合せは拒否する。
- プロパティの全体統合は通常のYAMLマッピングを対象にする。同じキーの値が同じなら保持し、異なる値・重複キー・文字列以外のキー・YAMLのalias／tag／anchorは拒否する。互換性のある値とコメントは残すが、全体統合でYAMLの書式が整えられる場合がある。部分抽出は元のプロパティを移さない。

## 保存と復旧

プレビューはファイルを変更しない。実行時に本文と対象ファイルを再確認し、外部編集やVaultの切替があれば古いプレビューでの保存を拒否する。編集中の本文を先に保存し、未解決の保存競合がある間は実行できない。

複数ファイルの更新中に中断した場合は、復旧用記録を保持して再起動時に処理を再開する。途中で対象が外部編集されていた場合は上書きせず、競合を表示する。保護対象・除外対象のノートや安全でないパスには書き込まない。

この機能は明示的な画面操作または上記ショートカットで使う。MCPからの抽出・統合は対象外。永続する抽出設定や新しいテンプレート管理画面は追加しない。
