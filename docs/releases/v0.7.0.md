# TSUZUNE v0.7.0

## 主な変更

- **編集と参照** — Wikiリンクのノート・見出し・ブロック補完、タブ固定、ファイル一覧の操作改善。ノートの版履歴、選択範囲の抽出とノートの統合、表・脚注の編集、添付ファイル改名時のリンク更新に対応しました。
- **検索とタスク** — AND・OR・除外の組み合わせ、行や段落、タスク、プロパティ、正規表現での絞り込みを追加しました。検索索引をバックグラウンドで処理し、ファイル一覧などからノートをホバーで確認できます。ノート横断のタスク一覧から元の行へ移動し、完了状態を切り替えられます。
- **Canvas・Bases・移行** — Canvasのグループ化・整列・埋め込み・PNG書き出し、BasesのKanban列のドラッグ並べ替えとファイル移動に対応しました。Markdown、ChatGPT、Notion、Evernoteのデータをプレビューしてから取り込めます。
- **PDFと添付** — PDF内の検索、引用リンク、ノートのPDF書き出し、Vault内の音声・動画の再生に対応しました。数式、Mermaid、コールアウトはプレビューとPDF書き出しに反映されます。

### インストールと更新

新規インストールは `TSUZUNE-Setup-0.7.0.exe` をダウンロードして実行してください。既存のインストールはアプリ内で更新を確認できます。`latest.yml` と `.blockmap` は更新機能が使用します。

このインストーラーはコード署名なしで配布します。Windowsに発行元不明と表示される場合は、GitHubの公式リリースから取得したファイルであることを確認してください。Vaultは任意のフォルダーを選べます。Google Drive同期は任意で、初期状態はオフです。接続する場合はDesktop OAuthクライアントの設定ファイルを用意してください。
