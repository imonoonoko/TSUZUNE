# タブ固定（2026-10-30 P2-01）

参照中のMarkdownノートを、別ノートを開いた時の置換から守る。対象は通常のノートタブだけ。

- タブ横の「固定」ボタンで固定／解除する。固定状態をピン記号、ツールチップ、読み上げ名と押下状態で示す。Tabでボタンへ移動しEnter／Spaceで操作できる。
- 前回のタブ保存がない初回のノート表示・復元でも通常タブを生成し、同じ固定操作を提供する。
- 固定中に別ノートを通常表示すると、同じペインにそのノートのタブがあれば選択し、なければ新しい通常タブを追加する。同一ノートを開いた場合は固定タブを維持する。固定解除後は既存の置換規則に戻る。
- リンク、ファイル一覧、検索、ブックマークは共通のopen経路を使う。別ペインを指定する経路は指定先の固定状態を尊重する。別ペインに同じノートがあっても移動しない。
- 「新しいタブで開く」は既存どおり新しい通常タブを追加する。既存タブの選択は固定状態を変更しない。固定してもタブ順を変えない。
- 閉じるボタン、Delete、既存の閉じるショートカットは固定中も使える。固定は未保存本文を破棄する許可にならず、open／閉じる／分割は既存の保存・競合保護を通す。
- ワークスペースの保存、前回セッションの復元、ペイン移動・複製でも固定を保持する。既存の固定指定なしは解除状態。保存値はノートタブだけ任意のboolean `pinned` を許可し、他種タブや不正値は拒否する。
- 固定タブからの通常表示で新規タブが必要な場合、ワークスペース全体で200タブまでの上限に従う。失敗時は元タブと本文を維持する。作成自体が成功した新規ノートは残し、上限で表示できない場合は作成済みと明示して再作成を促さない。

受入はpublic behaviorの自動テスト、組込renderer、パッケージとインストール済み実行ファイルの隔離Vault、実画面のキーボード／ポインター操作で確認する。通常プロファイルを変更せず、Markdownを改変せず、本番ソース・実行ファイルの一致を確認する。

非対象：他種タブの固定、固定タブの自動並べ替え、閉じる禁止、全ペインをまたぐ重複抑止。
