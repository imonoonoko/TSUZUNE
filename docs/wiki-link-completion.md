# Wikiリンクの補完

Markdown編集とライブプレビューの編集中に、リンク先を入力すると候補が表示されます。

| 入力 | 候補 |
| --- | --- |
| `[[語句` | ノート名、パス、移動前のパス、YAMLの `aliases` に一致するノート |
| `[[#語句` / `[[ノート#語句` | 現在のノート／指定したノートの見出し |
| `[[#^ID` / `[[ノート#^ID` | 現在のノート／指定したノート内のブロックID |
| `[[##語句` / `[[^^語句` | Vault内の見出し／ブロックIDと本文 |

上下キーで候補を選び、Enter・Tab・クリックで確定します。Escで閉じると入力途中の文字が残ります。確定による変更は一回のUndoで戻せます。

YAMLの別名を選ぶと、確定したノートへのリンクに別名が表示名として入ります。すでに入力済みの表示名がある場合は、その表示名を保持します。
