# WEB-01

- Objective: TSUZUNEのMV3拡張へ組み込める既存本文抽出技術を比較する。
- Sources: Mozilla Readability、Defuddle、Obsidian Web Clipper、MarkDownloadの原作者資料とsource。
- Ownership: read-only research。
- Do: license、bundle形態、本文品質、SPA fallback、Markdown変換要否、更新負担を比較する。
- Do not: code編集、本番Vault書込み、cloud service提案。
- Output: 採用1案・不採用理由・最小integration・一次資料URL。
- Stop: license不明またはbrowser extensionへ持ち込めない場合は不採用。
