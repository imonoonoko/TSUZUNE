# Obsidian Graph Parity Purpose

## Problem
TSUZUNEの現行グラフはlocal／global探索、深度、絞り込み、pan／zoomを備えるが、固定リング配置であり、ObsidianのGraph viewにある力学設定、Filters、Groups、Display、time-lapseを備えていない。

## Target User
自分のMarkdown VaultをTSUZUNEだけで日常運用し、Obsidianに近い知識探索を行いたい個人利用者。

## Current Workaround
固定配置のTSUZUNEグラフで近傍を確認するか、Obsidianを別途開いてGraph viewを使う。

## Why Now
P0-1〜P0-4で非破壊な探索基盤と操作上限が安定し、描画方式と設定モデルを交換できる段階になった。

## Desired Outcome
Obsidian公式Graph view／Local Graphの文書化された機能をTSUZUNE内で使え、同一Vaultに対する表示対象と操作結果が一致する。

## Success Definition
公式機能対応表を満たし、比較Vaultでnode／edge包含、設定効果、主要操作、性能、Markdown不変を再現可能なレポートで確認できる。
