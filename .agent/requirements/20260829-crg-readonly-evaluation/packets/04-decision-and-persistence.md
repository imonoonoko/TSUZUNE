# Packet 04: decision and persistence

- **Objective:** Integrate the verified result into one durable evidence packet and the minimum canonical TSUZUNE state.
- **Ownership:** parent; `final-report.md`, `state.json`, existing CRG roadmap candidate, and at most one execution record.
- **Acceptance:** clear advance/Held decision; evidence and unknowns; no production claim; workflow consistency; fresh-revision TSUZUNE write, read-back, backlink/link verification, and unique-record search when a write is required.
- **Forbidden:** product/runtime installation, broad MOC duplication, multiple execution records, or promotion beyond the measured decision.
- **Stop/escalate:** stale revision, conflicting current state, or any proposed scope beyond the Gate 0 evidence.
