# Packet 24 — Light, observation, and visual truth

- objective: 宇宙画像で何が実際に観測され、波長・filter・色合成・dynamic range処理によって何が人間可視像へ変換されるかを調べる。
- sources: NASA／ESA／STScI／ESO等の公式imaging documentation、instrument pages、original methods。
- ownership: read-only web research。source-provenance recordのみ返す。
- do: emission、absorption、scattering、dust extinction、spectral line、false／representative color、projectionの違いを明示し、芸術表現が科学画像を偽装しないための境界を返す。
- do not: repo／TSUZUNE編集、画像download、完成report、subagent spawn、物理simulationの実装。
- verification: 少なくとも可視光／赤外線／X線またはradioの3観測帯と、色合成の公式説明を一次資料へ結ぶ。
- stop: 「実在宇宙を参考にする」が写真模倣や肉眼像の誤認にならない判断基準が揃った時。

## Result

Complete。emission、scattering、absorption、spectral tracer、visible／IR／radio-mm／UV／X-ray、calibration、stretch、representative color、redshift、lensingを公式資料20件で確認した。統合成果は`results/40-light-observation-and-visual-truth-research.md`。
