# 観測宙域 芸術優先再設計 Orchestrated Plan

この文書が、R5利用者不採用後のrepository側の現在状態を所有する。`art-redesign-state.json`、既存の `plan.md` と `state.json` はR5までの歴史的完了証拠として保持する。2026-09-04、工房主がTSUZUNEの観測開始を生命の起点とする `TSUZUNE LIFE Weather` を採用し、Gate 0の時間証拠棚卸し、Gate 1 profile生成、Gate 2の隔離描画接続まで進んだ。

## Goal

TSUZUNEに集めたノートが、本人のVaultからしか生まれない生成芸術として立ち現れ、操作せず見続けたくなる観測宙域を、製品から隔離したWebGL2 prototypeで検証可能にする。

## Success criteria

1. 基準5作品から借りる運動原理と、借りない表層表現が区別されている。
2. 現在の本番Vaultで観測できる各ノートが一対一の粒子となり、内容・時点・リンク・構造が独立した観測トラックとして運動へ影響する。
3. 関係が引力・解放・反発へ移り、未知の相手候補も変化することで、固定graphや恒久clusterへ収束しない。
4. Archive Weatherを一つのmotion prototypeとして起動でき、利用者鑑賞で判定できる受入条件と停止線を持つ。

## Constraints

- R0〜R5は利用者鑑賞不採用。技術証拠としてのみ保持する。
- 実用Graph、検索、Contextの責務を観測宙域へ重複させない。
- 存在相そのもの、自然科学的量子simulation、真の意味関係を主張しない。
- Gate 1では純粋なprofile生成coreと評価scriptだけをproduct sourceへ置く。描画接続、本番反映、Git delivery、利用者画面の前面化は行わない。
- dirty worktreeの既存変更を保持する。
