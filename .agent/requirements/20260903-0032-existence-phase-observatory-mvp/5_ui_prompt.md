# 観測宙域 MVP UI Prompt（R5）

## Intent

空にgraphを置くのではなく、知識の局所的な分節である実ノートが、広い暗い場を自律的に漂い、寄り、離れ、別の一時的なまとまりへ変わり続ける窓にする。操作しなくても成立し、答えや固定分類を提示せず、次の関係を見つける余白を残す。

## Visual grammar

- 一枚の深い緑黒の空間に、最大72個の実ノート粒子だけを置く。
- 粒子は大半の時間を穏やかに漂い、局所規則から疎密が生まれてはほどける。短い残光と淡い局所発光で方向と密度を感じさせる。
- node間の線、固定星座、円で囲んだcluster、中心node、背景用fake star、名前の常時表示は置かない。
- 視覚のピークを常態にしない。暗部と余白も変化の一部にする。
- 色はNight Workshopの青緑白へ限定し、量子・宇宙をneonやHUDの記号で説明しない。

## Interaction

- 常設buttonは一時停止／再生だけ。通常は沈め、hover／keyboard focus時に読める。
- pointerで粒子を観測すると短い名前、clickで元noteを直接開く。
- Canvas一つをkeyboard focusにし、矢印で粒子を巡り、Enter／Spaceで開き、Escapeで解除する。
- reduced motionでは静止構図を表示し、再生操作を出さない。

## Truthful language

「表示する光は実在ノート。近さ、動き、光、集まりは現在の観測表現であり、関係、分類、重要度を確定しない」と伝える。存在相そのもの、真の集団、意味距離、存在度とは呼ばない。
