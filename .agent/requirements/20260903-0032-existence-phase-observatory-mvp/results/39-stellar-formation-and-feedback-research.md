# 恒星誕生・feedback・物質循環調査

観測日: 2026-09-05。STAR-FORMATION調査packetと親Agentの追試検索を統合した。制作で採用できるのは因果骨格であり、特定天体の未観測3D形状ではない。

## 因果骨格

拡散ISM → 冷却・圧縮・分子化した雲 → 密度揺らぎ／filament／dense core → 重力収縮と角運動量による降着円盤 → 原始星と双極jet／outflow → 核融合星 → UV・恒星風・H II／PDR・shock → 雲の圧縮または散逸 → 大質量星だけが超新星と元素放出 → ISM

これは一本道ではない。coreの全てが星になるわけではなく、feedbackは場所により圧縮、散逸、再流入を生み、超新星は十分に大質量な星だけの分岐である。

## 強く支持されるclaim

- 星形成雲は低温、高密度、超音速乱流、磁場、自己重力、放射、化学、塵が同時に作用する多次元系である。重力だけ、磁場だけ、乱流だけの一原理に還元できない。
- GMCは典型的に数十pc級。54銀河のPHANGS解析ではCO-visible cloud lifetimeは約5〜30 Myr、星形成領域が露出してからfeedbackで散逸する時間は約1〜5 Myrで、環境差が大きい。
- 原始星への物質は角運動量により円盤を作り、概ね円盤へ垂直な双極jet／outflowを生む。source/disk 0.1〜100 au、envelope 100〜100,000 au、parent cloud 100,000〜1,000,000 auという複数尺度へ影響が連続する。
- jet先端は装飾的な光線ではなく、周囲物質へbow shockやshock layerを作る。CO、SiO、dust continuumなどは異なる成分を追う。
- 大質量星のUV、photoionization、恒星風はPDR、ionization front、H II領域を作り、物質を加熱・化学変化・流出させる。
- 超新星残骸はforward/reverse shock、元素の異なる分布、高温ガス、高energy粒子を数百〜数千年以上残す。

## 重要な反証

- 原始星outflow cavityが年齢とともに単調に広がり、星の成長を止めるという単純像はOrion 304原始星の解析で支持されなかった。cavityを進行度meterにしない。
- outflowが雲へ衝突しても、次の星形成を誘発したと直ちに断定できない。
- 磁場対乱流の優劣、大質量星の円盤降着、jet駆動機構、feedbackによるtriggered star formationは参照天体なしに確定しない。

## 制作判断

Stellar Nurseryは、暗いcore、供給流、降着、双極jet、shock、PDR／H II前線、異年齢の星が一つの場所に共存できるため、持続する立体作品の基盤として強い。ただし実時間は数十万〜数千万年であり、動かすならartistic time compressionと明記する。単なる煙、中心吸引、綺麗な渦、最後の花火へ還元しない。
