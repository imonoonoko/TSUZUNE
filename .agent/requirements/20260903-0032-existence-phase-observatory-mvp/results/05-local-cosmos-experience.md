# Result 05 — Local Cosmos Experience

## 結論

camera調整ではなく、描画単位を全量Graphから局所scene projectionへ置換する。初期全景、全量の薄い残像、全景ボタン、pan／zoom、規則的な背景星、常時の技術captionを削除する。

## 採用

- 1場面は実在するMarkdownノートだけを最大9件表示し、解決済み明示Wiki linkだけを結ぶ。
- 全景を置かず、開いた直後から局所sceneを表示する。
- 場面間はcamera移動せずcrossfadeする。通常時も星の位置は動かさない。
- 背景はNight Workshop寄りの暗色とvignetteだけにし、dataに見える装飾点・装飾線を置かない。
- ノート名は通常非表示。hover／focus／選択時の一件だけ短く見せ、完全名は`title`／ARIAへ残す。
- 操作は一時停止／再生と次の場面に限定し、星の選択は再生を止める。

## 境界

表示位置・星座形状・場面順は読める構図のための配置であり、意味距離・重要度・因果・存在度を表さない。通常Graphが全体把握を担う。局所抜粋に発見価値がなければ演出を増やさず撤回を検討する。
