# REFERENCE-MOTION 結果

## 観測事実

- Tendrils: 各粒子が速度場へ運動履歴を残し、その場が後続粒子を変える再帰的advection。noiseは形態のscaleを循環させる。
- Holtset Flow: Three.js／WebGPU experimentであること以外の作品固有規則は一次ページから確認できず、詳細はunknown。
- Unsupervised: MoMA archive由来の資料空間を連続的に横断し、固定分類ではなく変容するarchiveとして提示するnon-interactive作品。
- FLUX: 時間をz軸に持つnoise field、減衰するtrail、idle auto-pilot、seed再現を分離する。
- Miri Particle Flow: GPU常駐状態、寿命・再出現・短い減衰痕跡、無入力の自律運動と局所的pointer干渉を持つ。

## 統合

借りるのは、局所規則による連続遷移、短い履歴が次の状態へ影響すること、自律運動、減衰、再出現である。借りないのは、各作品固有のpalette、粒子数、流体線、GAN、camera/mic、preset、HUDである。

experiential grammar: 完成した全体図を見せず、局所的な状態遷移と消えきらない短い履歴を見せる。観察者は対象を並べ替える操作者ではなく、必要なら局所条件を弱く撹乱するだけとする。
