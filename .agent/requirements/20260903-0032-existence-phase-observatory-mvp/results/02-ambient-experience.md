# AMBIENT-01 — 観測宙域の最低操作・鑑賞体験

> **Phase 1 historical proposal:** 全景、camera、確認式openを含む箇所は利用者受入FAIL後に棄却された。現行R2は `results/08-visual-refinement.md` と `5_ui_prompt.md` を正本とする。

## 結論

MVPの核は「自動で意味を発見させること」ではなく、明示 Wiki link だけで作られた既存の知識景観を、**止まって見えるほどゆっくり、しかし次のまとまりを待ちたくなるように**見せることである。観測宙域は通常 Graph の代替でも、存在相そのものの模型でもない。現在の Vault と表示規則から得た有限の観測断面であり、利用者が自分でノートを開くまで、何も確定・保存・推薦しない。

このため、最初の実装は「全体像 → 一つの明示リンクのまとまり → 余白 → 次のまとまり」を反復するだけに留める。意外性は生成や隠れた類似性ではなく、普段の能動探索で見落とす既存の隣接関係を、読む必要のない速度で露出することから得る。

## 現行境界と設計上の前提

- 通常 Graph は Global / Local の探索面であり、既にズーム、パン、ノード操作、設定、グループ、タイムラプスを持つ。観測宙域は同じ graph data を読む別 presentation とし、既存設定・camera・node position を書き換えない。
- 現行 Graph の node はクリック以外に drag や context menu を持つ。鑑賞中にそれらを表へ出すと「何をすればよいか」を考えさせるため、観測宙域では選択とノートを開く確認だけを前面の経路にする。
- edge は既存の明示 Wiki link だけ。星の距離・明るさ・色・大きさを真理、重要度、存在度、因果の一つの尺度として読ませない。caption はこの制約を毎場面で短く再確認できるようにする。

## 2 分間の体験譜（実機評価用の試奏）

これは出荷時の標準 tempo を固定する仕様ではない。要件どおり標準 tempo は実機鑑賞で決めるため、二分間・三場面という受入条件を評価するための初期スコアである。各場面の秒数は、下記の順序と「読める静止」を崩さない範囲で調整する。

| 時間 | 画面の状態 | 利用者が受け取るもの | 操作の必要 |
| --- | --- | --- | --- |
| 0–15 秒 | 全体を静止に近い状態で見せる。caption は `観測断面: 明示リンク / Vault全体 / 現在`。 | 今見ているのが Vault の条件付き表現だと分かる。 | なし |
| 15–42 秒 | 第一場面へ一度だけ穏やかに approach。注目集合の主要ノート名だけを出し、他の星は消さず暗くする。 | 一つの既存のまとまりを、ラベルを読める時間で眺める。 | なし |
| 42–55 秒 | release。強調をほどき、全体へ戻る余白。caption は残す。 | 次を予告せず、視線を休ませる。 | なし |
| 55–82 秒 | 第二場面。第一と重ならない注目集合へ移る。 | 「別のまとまりもある」と感じられる。 | なし |
| 82–95 秒 | release。camera も node も急に反転させない。 | 比較・余韻の時間。 | なし |
| 95–120 秒 | 第三場面を提示し、終端でゆっくり全体の安定状態へ戻る。自動的に最初へ巻き戻さない。 | さらに見たい場合だけ、次の巡回を待つ／再生する余地。 | なし |

場面中の caption 例は `観測断面: 明示リンク / Vault全体 / 現在 — 「研究ノート周辺」` とする。「発見」「重要」「因果」「正解」のような評価語を入れない。星座名は、保存済みの固定分類名ではなく、選択規則を説明する中立名（例: `明示リンクの連結領域`、必要なら主要ノート名）にする。

## 常時 UI と一時 UI

### 常時 UI — 鑑賞を邪魔しない、読める最小の事実

- 全画面に近い Universe canvas。背景に particle、点滅、音、3D 効果は置かない。
- 左下の一行 caption。これは操作ではなく、edge の根拠・対象範囲・現在性を示す常時の表示契約である。
- 注目中だけの星座名と主要ノート label。label は一定時間に一度で、場面遷移中に全文を走らせない。
- 選択された星には、色以外にも外側の細い輪と keyboard focus ring を使う。自動巡回は node を選択・開かない。

### 一時 UI — 開きたい時だけ、三操作を現す

pointer 移動、Tab による focus、または星を明示選択した時だけ、下部 toolbar をゆっくり現す。通常時は fade out するが、keyboard focus 中は消さず、focus を隠さない。

1. `一時停止 / 再生` — camera と場面切替を同時に止め、現在の位置を保つ。
2. `全体へ戻る` — 選択を外し、全体の安定位置へ一度だけ戻す。
3. `ノートを開く` — 選択済みの既存 node だけを元ノートで開く。未選択時は無効で、巡回や hover だけでは絶対に開かない。

wheel zoom と背景 drag は補助的な既存探索操作として使えるが、toolbar に追加しない。星を一回クリック／Enter すると選択と一時停止だけを行い、二回目の確認操作（`ノートを開く`）で初めて遷移する。これにより、鑑賞から思考への移行は一手で可能だが、autoplay が利用者をノートへ連れ出すことはない。

`?` または caption の help disclosure では、`星と線は明示 Wiki link による現在の Vault 表現であり、存在相そのものや重要度を示さない`、及び色・輪・label の意味を確認できるようにする。これは主操作ではないため、常時三操作には数えない。

## Motion grammar と視覚疲労の規則

| 要素 | 許可する振る舞い | 禁止する振る舞い |
| --- | --- | --- |
| camera | overview、approach、dwell、release の順で、一場面につき一方向の連続補間。dwell では止まる。 | jump cut、往復、追従、読めない速さの zoom、場面中の再 framing。 |
| 星 / Force | 既存 simulation の微細な漂い。注目集合は opacity と輪で浮上させる。 | 全 node の常時パルス、bouncy motion、重力・軌道を意味付ける演出。 |
| edge | 注目集合だけ opacity を上げ、node より後ろ、円周で終える。 | 光が edge を走る、点滅、明示 link 以外の推論線。 |
| label / caption | label は scene の dwell に合わせて fade in / out。caption は位置を固定する。 | ticker、文字送り、同時に多数の label、caption の位置移動。 |
| 空白 | 場面の前後に視線休止を置く。次の対象を事前に煽らない。 | 無限ループを悟らせる短周期の反復、操作を促すカウントダウン。 |

一度の場面遷移では、camera 移動か注目度の移行のどちらかを主動作にする。camera が動く最中に label・edge・node size を同時に大きく変えない。描画更新中も現場面を保持し、新規 node を中央に飛ばさない。0 / 1 note / 0 link / 描画失敗は要件の静かな fallback を優先し、「何もない＝関係がない」と表現しない。

## Reduced motion

- OS の `prefers-reduced-motion: reduce` と、存在する場合の app 側低減設定を優先する。両方とも未指定なら通常 motion にする。
- reduced motion では camera の自動 zoom / pan、Force の見える運動、反復的な pulse を止める。全体位置は固定する。
- 場面の差は、選択集合の opacity・輪・label の短い crossfade（必要なら即時切替）だけで示す。自動場面切替自体は続けられるが、`一時停止` は通常時と同じく常に効く。
- `一時停止` は reduced motion の代替ではない。前者は巡回の状態、後者は不必要な運動を減らす表示選好である。
- control と注目 node は色だけに依存せず、輪、形状差、visible focus、名前で識別する。toolbar を pointer だけで出す設計にはせず、Tab focus でも到達できる。

これは、5 秒を超えて自動開始する動きには利用者が pause / stop / hide できる仕組みを求める WCAG 2.2 SC 2.2.2 と整合する。また `prefers-reduced-motion` は、非必須運動を最小化したいという利用者選好を検知する標準機構である。外部根拠は末尾に残す。

## MVP / Future / Reject / Experiment

| 区分 | 採否 | 内容と理由 |
| --- | --- | --- |
| MVP | 採用 | 明示 Wiki link の連結領域または近傍を、決定論的に三場面選び、上の score で巡回する。caption、三つの一時 control、pause、reduced motion、静かな空状態まで。既存 Graph と同じ data / rendering 基盤を読む。 |
| Future | 保留 | 三段階速度、通常 Global Graph への注目対象引継ぎ、最近更新の淡い表示。どれも鑑賞価値の実測後にだけ検討する。 |
| Reject | 不採用 | game 化、streak、通知、報酬、音、particle、3D free-flight、常時 HUD、重要度を装う星の階層化、LLM / embedding による「発見」edge、自動ノート作成。操作ゼロと表現の誠実さを損なう。 |
| Experiment | 比較する | 同じ固定 Vault fixture で、(A) 連結領域、(B) 主要 node の近傍、(C) 既存 Group query の三選択規則を比較する。どれが説明を要せず、二分間の静かな視聴を保てるかを観察してから MVP の selector を決める。 |

## 最強の反証と評価方法

**最強の反証:** 自動巡回は知識の見落としを助けるのではなく、動くグラフを眺めるだけの screensaver になり、任意の link の近接を「意味がある」「重要だ」という誤った印象に変えてしまう。ならば通常 Global Graph の静止表示より鑑賞・理解・ノートを開く意欲のどれも改善せず、理論上の安全境界だけを曖昧にする。

この反証を避けるため、実装前後で同じ Vault fixture・同じ scene seed を使い、静止 Global Graph と観測宙域を別セッションで比較する。二分間を操作なしで見た直後に、以下を記録する。

- **操作ゼロ:** pointer / key / wheel / drag の回数が 0 の状態で、三つの異なる場面が急な jump なく完走したか。画面録画またはイベント計測で確認する。
- **見続ける価値:** 利用者が中断なく二分間見たか、見た後に「もう一場面を見る」または「このノートを開く」を自発的に選んだか。単なる滞在時間ではなく、各場面で気づいた明示 link を一つ言えるかも聞く。
- **開きたい時だけ開ける:** autoplay / hover 由来の note open は 0 件、選択後の確認操作による open のみであること。開かれたノートの理由を利用者が自分の言葉で説明できること。
- **表現の誠実さ:** 「この星座は正解・重要度・存在相そのものを示す」と読んだかを短く確認し、その誤読が一件でもあれば caption / encoding を修正し、selector の採用を止める。
- **快適さ:** motion discomfort、読みづらさ、制御を見つけられない事象を記録する。reduced motion では camera の連続移動が 0 で、三操作と note open が keyboard でも成立することを確認する。

MVP を進める判定は、上の三条件が同じ試奏で満たされ、かつ表現の誠実さに失敗がないこと。満たさなければ Future 機能で装飾を足さず、scene selector、caption、tempo、または観測宙域そのものの採用を見直す。

## 三条件への設計監査

| 提案 | 操作ゼロ | 見続ける価値 | 開きたい時だけ開ける |
| --- | --- | --- | --- |
| 自動の overview → dwell → release | 開いた直後から完結する。 | 場面と余白の差で、次のまとまりを待てる。 | 自動で node を選択・遷移しない。 |
| 常時 caption と限定 label | 説明を探す必要がない。 | 見ている対象と根拠を失わない。 | note title は出ても開かない。 |
| pointer / focus 時だけの三 control | 普段は不要。 | 負担なら即座に止められる。 | 開くには選択後の明示確認が必要。 |
| reduced motion の固定 camera | 動きを止めるための操作を強制しない。 | 不快感を減らして場面の差を読める。 | 既存と同じ確認経路を保持する。 |
| 説明可能な明示 link のみ | 意味付けを調べる必要がない。 | 偶発的な隣接を安全に眺められる。 | AI 推薦による自動遷移を持たない。 |
