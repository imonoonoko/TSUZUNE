# UI Prompt

既存TSUZUNEの静かな紙色・3ペイン構成を維持する。新しい機能をダッシュボード化しない。

## Graph

- 中央ヘッダーの「編集」「プレビュー」に「グラフ」を追加する。
- グラフ選択時だけ中央本文をグラフへ差し替える。
- 中心ノートは最も強く、隣接ノートは控えめに表示する。
- 有向辺は矢印でリンク方向を示す。
- SVGは辺、HTML buttonはノードとして使い、フォーカスリングとEnter/Space操作を提供する。
- 情報がない場合も「このノートには解決済みリンクがありません」と明示する。

## Google

- 上部右側に「Google」ボタンを置く。
- 押すと小さな設定パネルまたはダイアログを表示する。
- 組み込み設定あり・未接続時: 「Googleでログイン」を主操作として表示する。
- 組み込み設定なし: 「OAuth JSONを選ぶ」を表示する。
- 独自JSONの選択は「詳細設定」を開いた場合だけ表示する。
- 接続済み: アカウント名、メール、最終同期時刻、「同期を確認」「同期を実行」「切断」。
- 同期実行前に件数を表示し、競合がある場合は説明する。
- 「Googleログインで個人情報を自動取得する」という誤解を生まない文言にする。
- 権限説明は「TSUZUNEが作成・選択したDriveファイルだけ」と短く表示する。
