# Purpose

TSUZUNEを、ローカルMarkdownの安全性を保ったまま、本人専用の知識を継続的に増やせる日常用ノートへ進化させる。

今回の価値は次の2点に絞る。

1. Wikiリンクの周辺関係を視覚的にたどり、関連ノートへすぐ移動できる。
2. 本人のGoogleアカウントで認証し、TSUZUNE専用のGoogle DriveフォルダとMarkdownを手動同期できる。

Googleログインは本人確認とDriveへの認可手段であり、Google内部の推定属性を取得する仕組みではない。本人に関する情報を増やす入口は、本人がTSUZUNEへ保存したMarkdownと、本人が明示的に同期対象へ置いたデータとする。
