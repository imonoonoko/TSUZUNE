# Purpose

Make the three high-frequency navigation actions usable for a person who does not write Markdown:

1. offer a small, predictable template set even when the Vault has no `90_テンプレート` files;
2. replace the unreliable native rename prompt with an in-app, keyboard-accessible rename dialog;
3. expose the graph's existing zoom and fit behavior as the compact controls users expect from an Obsidian-like graph.

The slice must preserve Markdown as the source of truth, keep existing custom templates and rename safety checks, and avoid adding a database, dependency, or parallel graph engine.
