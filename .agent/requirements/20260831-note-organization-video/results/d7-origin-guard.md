# D7 Original Philosophy Guardian

## Decision

追加source featureは停止する。現在のInbox actionは原思想に一致し、次の機能を正当化する実利用摩擦はまだない。

## Canonical mapping

- 人間優先: capture時に分類・folder・tag・titleを要求しない。
- 知識循環: Inboxを情報墓地ではなく後から再発見・再利用する玄関にする。
- 構造探索: AIは既存検索とContextから候補を提案し、構造を自動確定しない。
- 探索は大胆に、書込みは慎重に: proposalとapprovalを分離し、曖昧ならInboxに残し、一件だけrevision-checked move/readbackする。

## Reject

- all-Vault classification, batch move, automatic link or promotion
- Processed, Archive, or new History
- organizer MCP, DB, review queue, Vector DB, embedding index
- background Agent, daemon, Hook, rule engine
- mandatory capture form, title, tag, or classification
- Graph appearance, link count, or classification rate as success metrics

## Reopen only when

実利用で同型のcapture摩擦が独立2件以上観測されるか、一件の人間承認付き整理で既存経路が成立しない具体的証拠が出た時。
