# T1 — 指定タスクから引き継ぐ判断

Source task: `codex://threads/01a053d2-9e0a-7243-b1e3-89b339e9438a`

## 現在にも採用できる判断

- メモ、ノート、カードを固定された別形式ではなく、同じ知識が成熟する状態として扱う。
- 学びは `捕捉 → 原典・根拠・時点 → 自分の理解 → 再利用できる主張 → 関連ノート → 使う場面 → 見直す条件` で循環させる。
- 価値の判定はリンク数ではなく、判断を変えたか、再利用できたか、離れた知識を有用に接続したかで行う。
- 将来の自然利用で最大10件を試す小規模評価は、TSUZUNEの既存方針と整合する。

## 採用済みの現行境界

- 学びメモ導線はすでに実装・本番受入済みであり、今回それを別方式へ置換しない。
- カードは再利用可能な主張になった状態であり、全ノートへ強制する型ではない。

## 保留または不採用

- 全Vaultの自動分類、自動昇格、自動リンク、自律Hook。
- カード数、リンク数、Graph外観を成功指標にすること。
- 最大10件の自然利用試行の成果は未確認であり、効果を確定扱いしない。
