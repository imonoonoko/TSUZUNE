# Purpose

MCP `search` が AI更新履歴(`50_履歴/**`)を検索結果に混入させ、目的の知識ノートが埋もれる問題を解消する。

- 実測: `"X1-T1 本番反映"` の検索で9件中8件が `50_履歴/AI更新` の監査ノートだった。
- ボールト設計ノートも「AI revisionを通常検索・Graph・Contextから既定除外する」を未実装課題として明記している。

本スライスは **search のみ** を対象とし、既定で `50_履歴/**` を除外、`include_history: true` で明示的に含める。

監査追跡のため、`fetch`(path指定)と `get_backlinks` の履歴アクセスは維持する。
